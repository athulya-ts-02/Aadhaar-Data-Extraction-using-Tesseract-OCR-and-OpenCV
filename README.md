# Aadhaar Data Extraction using Tesseract OCR and OpenCV

A Python-based application that extracts key information from Indian Aadhaar cards using Optical Character Recognition (OCR). The project uses OpenCV for image preprocessing and Tesseract OCR for accurate text extraction.

## Features
- Extracts text from Aadhaar card images
- Detects and retrieves:
  - Name
  - Aadhaar Number
  - Date of Birth / Year of Birth
- Image preprocessing using OpenCV to improve OCR accuracy
- Uses Tesseract OCR for text recognition

## Technologies Used
- Python
- OpenCV
- Tesseract OCR
- Regular Expressions (Regex)
- NumPy
